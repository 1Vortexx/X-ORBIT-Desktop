LONG HAUL - THE RETURN TRIP
Campaign and voice recording package, edition 1
19 November 2026

START HERE
output/pdf/Long_Haul_The_Return_Trip_Full_Campaign.pdf
The complete campaign master, with chapter/mission contents and PDF bookmarks.
40 missions, 104 scenes, 827 allocated spoken entries, 112 pages.

SEND TO ACTORS
actors/ contains one styled PDF and one plain-text UTF-8 recording script per speaking character (20 of each).
Each packet includes character gender, playing age, direction, previous-line cues, mission/scene context
and every assigned line in this edition. Send only the relevant character file to each performer.
The first full draft supersedes earlier audition wording.

RECORDING
File names should match line IDs. Cues, directions and IDs are not spoken.
Record all branch alternatives separately. Identical archival source lines can reuse a director-approved take.
Do not add effects. Keep clean dry audio and head/tail room.
Character gender and playing age are creative specifications, not restrictions on performer identity.
Casting choices and names for supporting characters in this edition are proposed for approval.

MASTER DATA
Long_Haul_Full_Campaign.md is the editable combined master with IDs.
Dialogue_Recording_Manifest.csv maps every recording ID to actor, scene, direction, cue and exact spoken text.
Cast_and_Line_Counts.csv is the casting and workload sheet.
source/ preserves the authored chapter documents and runtime lines.
build_package.py regenerates the exports with ReportLab and pypdf; fonts use embedded local Arial and Georgia.

SCOPE AND LIMITS
This is a complete end-to-end narrative first draft, not an implemented or playtested campaign.
The 42-hour target allocates playable driving, investigation, maintenance and deliveries.
It is not 42 hours of dialogue; all allocated branch text totals 6,332 spoken words.
All branch text is longer than any one playthrough's spoken selection.
The two documentary radio episodes are separate productions and are not included as campaign voice scripts.
No paid actors, recordings, rights clearances or game implementation are supplied by this package.
A final editorial table read and level-design playtest are still needed before locking recording.

LANGUAGE
Mature language appears at designated anger, danger and confrontation beats.
No slurs or improvised profanity are required.

ACTOR PDF EDITION
Each styled actor PDF matches the master's desert cover, warm paper, copper accents and typography.
Use the PDF for reading and recording; use TXT for editable text. Both share the original recording IDs.

ROLE ASSIGNMENT FOLDERS
actors/Women - 11 characters, each with a PDF and text script.
actors/Men - 9 characters, each with a PDF and text script.
Each folder has Roles.csv with playing ages, voice direction and line counts.
There is also a separate downloadable ZIP for each group.
