Jitter

Messaging for your desktop.

Send a message, catch up with a group, or call a friend. Jitter opens in its own window from your desktop app list.

Install with Chrome or Edge.

Inside Jitter

Conversations
Reply to a friend, react to a message, or bring everyone into a group chat.
Calls
Start a voice call from a direct message. Share your screen when it’s easier to show what you mean.
Appearance
Choose a theme in Settings. Keep the original dark inbox or switch to a layout like Gig Listing or Message First.

Desktop setup

Select and confirm in your browser. Once installed, open Jitter from your apps and sign in.

How to install from the browser menu

ChromeOpen the browser menu and choose Cast, save, and share → Install page as app.

EdgeOpen Settings and more → More tools → Apps, then choose Install this site as an app.

Safari on MacOn macOS Sonoma or later, choose File → Add to Dock, then select Add.
